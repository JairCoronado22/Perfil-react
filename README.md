# Portafolio de Jair Coronado

Portafolio profesional frontend construido con **React 19**, **Tailwind CSS 4**, **Vite** y **Lucide React**.

## Características

- Diseño profesional y completamente responsive.
- Tema claro y oscuro con persistencia en `localStorage`.
- Navegación activa y menú móvil.
- Secciones de perfil, habilidades, fortalezas y disponibilidad.
- Tres proyectos destacados con previsualizaciones visuales.
- Modal de vista en vivo mediante `iframe` y enlace externo de respaldo.
- Accesibilidad básica, navegación por teclado y reducción de movimiento.
